ALTECAD CONCRETE — User Guide and Command Reference

Professional structural engineering tools for reinforced concrete design, footing, beam, column, pile, slab and wall detailing in AutoCAD.

Requirements

  • AutoCAD 2020 to 2026, Windows 64-bit (full AutoCAD; ALIGNER requires ActiveX / Visual LISP, so AutoCAD LT is not supported).
  • See the Installation Guide (PDF) delivered with the application for loading instructions.

General usage instructions

The ALTECAD CONCRETE ribbon tab contains six panels: STRUCTURE, FONDATION, ANNOTATION, COTA, BoQ and PLOTING. Start a command from its ribbon button or by typing its name on the command line. A typical project follows these five steps:

  1. Set out axes and draw the structure (STRUCTURE panel): create axes with AXIS-C or AXES-MIXTES, place columns with COLUMN-CONC, then draw beams (BEAM-AXIS, BEAM-SINGLE), walls (SHEAR-WALL, WALL-CONTINUOUS), slabs and purlins.
  2. Draw the foundations (FONDATION panel): isolated footings (FOOTING-ISOLATED), strip footings (STRIP-SOLE), piles (PILES), rafts and ground slabs.
  3. Annotate and dimension (ANNOTATION and COTA panels): annotate columns, walls, piles and slabs, number beams and purlins, create schedule tables, and add continuous dimensions.
  4. Extract quantities (BoQ panel): select the annotated objects, click the table insertion point, and export the results to CSV for Excel.
  5. Prepare sheets (PLOTING panel): generate layouts with viewports (LAYOUT-GEN) and combine them (ORGANIZE-LAYOUT).

Most commands create the layers they need automatically. Several commands can be undone with UNDO, as noted in the command reference below.

Panel STRUCTURE

AXIS-C

Automatic drawing of numbered axes from lines or columns, limited by a boundary polyline.

How to use
  1. Choose the scale [25/50/100] (default 100).
  2. Choose the creation mode [Columns/Lines] (default Lines).
  3. Select the objects: LINE objects in Lines mode; circles, polylines or blocks in Columns mode.
  4. Select the boundary contour (one polyline).
  5. The numbered axes are drawn, sorted by position and extended to the boundary.
Notes: Layer AXES is created automatically with linetype CENTER2 or AXES2. A boundary polyline is mandatory.

AXES-MIXTES

Generates vertical axes (1, 2, 3…) and horizontal axes (A, B, C…) in a single pass.

How to use
  1. Choose the scale [25/50/100] (default 100).
  2. Select the lines or arcs for the axes.
  3. Select the boundary contour (one polyline).
  4. Vertical and horizontal axes are drawn together.
Notes: Unlike AXIS-C, both directions are processed in one operation. Layer AXES is created automatically.

COLUMN-CONC

Draws reinforced concrete columns (rectangular or circular) with outline (layer COLUMN) and SOLID hatch (layer COLUMN_HATCH).

How to use
  1. Choose the shape [Rectangular/Circular].
  2. Enter the dimensions (b, h or diameter).
  3. Choose the mode [Single/Multiple].
  4. Single: click each insertion point and enter the angle. Multiple: select the axes; columns are placed automatically at the intersections.
Notes: Layers COLUMN and COLUMN_HATCH are created automatically. In Multiple mode, columns are placed at the intersections of the selected lines/polylines.

BEAM-AXIS

Automatically draws beams between columns (on axes).

How to use
  1. Choose the scale [50/75/100/150].
  2. Enter width, height and maximum span (m).
  3. Select the columns (layer COLUMN — polylines or circles).
  4. Beams are drawn automatically between neighbouring columns.
Notes: Connects columns whose center distance is below the maximum span; handles circular and rectangular columns. Layers S-BEAMS-2D and S-BEAMS-TXT are created automatically. The dimensions are remembered between calls.

BEAM-SINGLE

Draws single beams in a structural plan view.

How to use
  1. Choose the scale.
  2. Enter the width and height (m).
  3. Choose the alignment [Center/Left/Right].
  4. Click the START point (automatic snap to columns).
  5. Click the END point — repeat as needed.
Notes: Layers S-BEAMS-2D and S-BEAMS-TXT are created automatically. Works with fixed-height or variable-height text styles.

SHEAR-WALL

Draws reinforced concrete shear walls (layer SHEAR-WALLS) with a SOLID hatch sent to the back.

How to use
  1. Enter the wall thickness (m) — the last value is remembered.
  2. Choose the justification [Middle/Right/Left].
  3. Click the first point of the wall.
  4. Click the second point.
  5. The wall and its hatch are drawn — repeat for each wall.
Notes: Layers SHEAR-WALLS and SHEAR-WALL-HATCH are created automatically. The hatch is automatically sent to the back (DRAWORDER).

WALL-CONTINUOUS

Draws continuous double-line concrete walls with automatic junction clean-up.

How to use
  1. Enter the wall thickness (m) — the last value is remembered.
  2. Choose the justification [Center/Face].
  3. Click the START point.
  4. Click the following points (junctions are cleaned automatically).
  5. Press Enter to finish — an option to close the wall as a loop is offered.
Notes: Layer WALL-CONCRETE is created automatically. Object snaps stay active during input. Corner junctions are adjusted with a zero-radius FILLET.

SLABS-MIXED

Annotates mixed slabs on a formwork plan with type, thickness, level and span direction.

How to use
  1. Choose the slab type [Solid/Hollow/DAS/DPT] (default Hollow).
  2. Enter the thicknesses in cm when prompted: DAS (slab thickness, screed), DPT (thickness), Hollow (hollow-block height, screed) or Solid (thickness).
  3. Enter the level (default 0.00).
  4. Click inside each slab (press Esc to finish) — the slab outline is detected automatically.
  5. For Hollow and DAS slabs, select an edge to set the span direction.
  6. The span symbol and the annotation are drawn at the center of the slab.
Notes: Slabs are detected by clicking inside them (BOUNDARY), so the area must be enclosed. Layers SLAB_ANNOTATION and SLAB_STRUCTURE are created automatically.

PURLINS

Automatically draws purlins inside a boundary.

How to use
  1. Choose the scale [25/50/100/200].
  2. Choose the orientation [Vertical/Horizontal/Oblique].
  3. Choose the spacing type [Free/Center].
  4. Enter the purlin thickness, distance and height.
  5. Click inside each boundary — press Esc to finish.
Notes: Each purlin is numbered and the section annotation is placed on layer Purlins_Texts. Multi-boundary mode creates groups G1, G2… Layers BEAMS_PURLINS and Purlins_Texts are created automatically. The global G number is remembered between calls.

DROP-PANEL

Draws drop panels around columns or shear walls (outline and annotation).

How to use
  1. Enter the drop panel length (m), width (m) and thickness (m).
  2. Choose the position: 1=Center, 2=Lateral, 3=Corner (default 1).
  3. For Lateral, choose the edge (1=Bottom, 2=Top, 3=Left, 4=Right). For Corner, choose the corner (1=Bottom-Left, 2=Bottom-Right, 3=Top-Left, 4=Top-Right).
  4. Select the columns or shear walls.
  5. The outline and its label are drawn for each support.
Notes: Layers Drop-Panel-Outline and Drop-Panel-Annotation are created automatically. The label shows the thickness in cm (e.g. DP-25cm).

PATH-EXTRUSION-2D

2D extrusion of a profile along a path (cable tray or 2D profile).

How to use
  1. Select the profile section (the cyan profile).
  2. Click the intersection point between the axis and the section.
  3. Select the path (the black polyline).
  4. The edges and closing lines are drawn along the path on layer MS.
Notes: Layer MS is created in cyan. Linetype CENTER or AXES2 is loaded automatically.

RESA

Draws openings (reservations) in slabs and walls.

How to use
  1. Choose the mode [Click/Points/Exit]. Click: click inside the area — the outline is detected automatically. Points: enter 3 corners (width + depth).
  2. The reservation symbol is drawn automatically.
  3. Repeat for each reservation — choose Exit to finish.
Notes: Layer RESERVATIONS is created at load (yellow). In Click mode the area must be a closed outline in the drawing. The symbol includes the outline and crossed diagonals.

SUPERSTRUCTURE

Projects the superstructure onto a lower level.

How to use
  1. The elements (WALL-CONCRETE, COLUMN, SHEAR-WALLS) are selected automatically.
  2. Click the reference point on the UPPER level.
  3. Click the same reference point on the LOWER level.
  4. The elements are copied and formatted automatically.
Notes: Layers SUPERSTRUCTURE and SUPERSTRUCTURE_HATCH are created automatically. Linetype CACHE2 (FR) or HIDDEN (EN) is loaded automatically from acadiso.lin.

REINF-COLUMN-SECTION

Draws the reinforcement of a rectangular column section.

How to use
  1. Choose the scale [10/20/25/50].
  2. Enter the diameter of the longitudinal bars (mm).
  3. Enter the number of bars along the width (b) and the height (h).
  4. Enter the stirrup diameter (mm).
  5. Click the column rectangle.
  6. The complete reinforcement is drawn automatically.
Notes: The selected object must be a rectangle (LWPOLYLINE). Concrete cover 2.5 cm, stirrup ø6, bend radius 1.5 cm. Layers REBAR-STIRRUP and REBAR-LONG-BAR are created automatically.

REINF-CIRC-SECTION

Draws the reinforcement of a circular column section.

How to use
  1. Choose the scale [10/20/25/50].
  2. Click the column circle.
  3. Enter the diameter of the longitudinal bars (e.g. 16).
  4. Enter the number of bars.
  5. Enter the stirrup diameter (e.g. 8).
  6. The complete reinforcement is drawn automatically.
Notes: The selected object must be a CIRCLE. Concrete cover is fixed at 3 cm. Stirrup/spiral hooks at 7 cm. Layers REBAR-STIRRUP and REBAR-LONG-BAR are created automatically.

PIN-STEEL

Draws a reinforcement pin (open stirrup with hooks) between two steel bars.

How to use
  1. Run PIN-STEEL.
  2. Select exactly 2 rebars (circles, arcs or polylines).
  3. The pin is drawn between them.
Notes: Select exactly 2 objects, otherwise an error message is shown. Layer HA6 is created automatically. Top/bottom sorting is automatic.

SLOPE

Draws embankment slope hatching between a crest line and a toe line.

How to use
  1. Select the CREST line (top of the slope).
  2. Select the TOE line (bottom of the slope).
  3. Enter the spacing between strokes (m) — default 1.0.
  4. The slope strokes are generated and grouped automatically.
Notes: Layer Embankment is created automatically (color 190). Strokes alternate long (100%) and short (50%). All strokes are grouped into a single AutoCAD group. The operation can be undone (UNDO).

ALIGNER

Aligns a selection of objects on the edge or axis of a reference object. Supports rotated objects (oriented bounding box).

How to use
  1. Select the objects to align → Enter.
  2. Click the reference object.
  3. Choose the alignment mode (default: Left): Left, Right, Top, Bottom, CX (center horizontally), CY (center vertically).
Notes: Requires full AutoCAD (not LT) — ActiveX / Visual LISP is needed.

ROT-COLUMN

Rotates a column and its hatch by 90°.

How to use
  1. Click the column polyline (layer COLUMN).
  2. The column and its hatch rotate by 90° around the center.
  3. Repeat on other columns — press Esc to finish.
Notes: Works only on polylines of layer COLUMN. The hatch is searched in the column bounding box (layer COLUMN_HATCH). If no hatch is found, only the outline is rotated.

FILTRE

Isolates layers from a selection of objects.

How to use
  1. Select the model objects whose layers you want to list.
  2. In the dialog box, check the layers that must remain visible.
  3. Confirm with OK: the unchecked layers are frozen.
Notes: At least one layer must be checked. Cancel leaves the drawing unchanged. Use UNFILTRE to restore all layers.

UNFILTRE

Restores the visibility of all layers.

How to use
  1. Type UNFILTRE.
  2. All layers are immediately thawed and turned on.
  3. A confirmation message is displayed.
Notes: Complementary to FILTRE. Equivalent to -LAYER THAW * ON *. No selection required.

Panel FONDATION

FOOTING-ISOLATED

Draws isolated footings centered on columns, with name and dimension annotation.

How to use
  1. Enter the footing name (e.g. F2).
  2. Enter length, width and thickness (m).
  3. Choose the rotation [0/90].
  4. Select the supporting columns or walls.
  5. The footings are drawn automatically on each support.
Notes: Layers S_FOOTING and FOOT_ANNOTATION are created automatically (color 30). Styles FOOT_BOLD and FOOT_NORMAL are created automatically (Arial). Dimensions are displayed in cm (e.g. 120x120x60).

ROT-FOOTTING-ISOLATED

Rotates an isolated footing by 90° and repositions its text.

How to use
  1. Click the footing (layer S_FOOTING) to rotate.
  2. The footing, its name and its dimensions rotate by 90°.
  3. The texts are repositioned automatically at the top left.
  4. Repeat on other footings — press Esc to finish.
Notes: The footing must be in an AutoCAD group containing the rectangle (S_FOOTING), the name (style SEM_BOLD) and the dimensions (style SEM_NORMAL) on layer S_FOOT_ANNOTATION.

STRIP-SOLE

Generates strip footings by offsetting wall polylines.

How to use
  1. Enter the external offset distance (e.g. 0.20 m).
  2. Select the wall polylines (layer WALL-CONCRETE).
  3. The strip footings are created automatically on layer Wall-Footing.
  4. Linetype HIDDEN is applied automatically.
Notes: Layer Wall-Footing is created automatically (color 30, linetype HIDDEN). The alias SE can also be used. The offset is always guaranteed to go outward.

FOOTINGS-FUSION

Cleans and merges overlapping isolated footings.

How to use
  1. Select the footing polylines to clean (layer S_FOOTING).
  2. The command analyzes overlaps automatically.
  3. Interior segments are cut by TRIM.
  4. The result is clean geometry without overlap.
Notes: All modifications are grouped in a single UNDO. All layers are unlocked automatically in case of cancellation or error. Compatible with AutoCAD 2010-2026.

STRIP-SOLE-JOIN

Closes strip footings by joining their ends.

How to use
  1. Select the lines/polylines to close (layer Wall-Footing).
  2. The command pairs the closest elements automatically.
  3. Closing segments are drawn at both ends.
  4. The result is a set of closed rectangles.
Notes: Works on LINE and LWPOLYLINE of layer Wall-Footing. Pairing is based on the distance between midpoints. The operation can be undone (UNDO).

GROUND-SLAB

Annotates ground slabs with thickness and level.

How to use
  1. Enter the slab thickness (cm).
  2. Enter the level (m).
  3. Click inside each area to annotate.
  4. Repeat for each area — press Esc to finish.
Notes: The outline of the clicked area is detected automatically (BOUNDARY), the centroid is computed, and span symbols are drawn toward the slab edges. Layers Ground-slab and Ground slab_ANNOTATION are created at load.

GROUNDBEAM-AXIS

Automatically draws ground beams on column axes.

How to use
  1. Enter the beam width (m), height (m) and the maximum center-to-center distance between columns (m). The last values are remembered.
  2. Select the columns on layer COLUMN (window selection or All).
  3. Beams are drawn between neighbouring columns and labelled.
Notes: Works only on closed polylines (LWPOLYLINE) of layer COLUMN. Layers Gr-Beam and Gr-Beam-TXT are created automatically.

GROUNDBEAM-SIMPLE

Draws a single ground beam between two points, with automatic snapping to columns.

How to use
  1. Enter the beam width (m) and height (m). The last values are remembered.
  2. Choose the alignment [Center/Left/Right].
  3. Click the START point (it snaps to a column when you click on one).
  4. Click the END point.
  5. The beam is drawn and labelled with its section (e.g. GB 30x60). Repeat, or press Enter to finish.
Notes: Automatic snapping looks for columns on layer POTEAU. Layers Gr-Beam and Gr-Beam-TXT are created automatically.

PILES

Automatically lays out piles at the intersections of axes.

How to use
  1. Enter the pile diameter (m) — the default is remembered.
  2. Select the axis lines or polylines (grid).
  3. Piles are drawn automatically at each intersection.
Notes: Layer PILES_DRAWING is created automatically. Duplicates are removed with a 1 mm tolerance. The default diameter is remembered between sessions.

RAFT-CONCRETE

Annotates general raft zones. Similar to GROUND-SLAB but for rafts.

How to use
  1. Enter the raft thickness (cm).
  2. Enter the level (m).
  3. Click inside each raft zone.
  4. Repeat for each zone — press Esc to finish.
Notes: The outline is detected automatically (BOUNDARY). Span symbols are drawn toward the raft edges. Layers RAFT and RAFT_ANNOTATION are created at load.

Panel ANNOTATION

ANNO-COLUMN-RC

Automatic annotation of reinforced concrete columns.

How to use
  1. Choose the scale [50/100/200] (default 100).
  2. Select the columns on layer COLUMN (circles or closed polylines).
  3. Dimensions and areas are computed and an MTEXT annotation with a summary table is generated.
Notes: Works only on objects of layer COLUMN. Previous annotations are erased before redrawing. Text style ARIA-022 is created automatically.

NUMBER-BEAMS-CLASSIC

Manual sequential numbering of beams.

How to use
  1. Enter the starting number (default 1).
  2. Enter the prefix (e.g. E, N, B — default E).
  3. Click the beam texts/MTEXT in the numbering order.
  4. Press Enter to finish.
Notes: Works on TEXT and MTEXT objects. The format is prefix + number + original text (e.g. E1 - original text). Renumbering automatically removes the previous prefix (separator ' - ').

PURLINS-NUMBERING

Automatic renumbering of purlin groups.

How to use
  1. Run the command (no selection required).
  2. Layer Purlins_Texts is scanned automatically.
  3. All G* texts are renumbered G1, G2, G3… from top to bottom, left to right.
  4. A message confirms the number of renumbered items.
Notes: Works on layer Purlins_Texts only. The sorting tolerance per row is based on the text height. The operation can be undone (UNDO).

ANN-SHEAR

Automatic annotation of reinforced concrete shear walls with their thickness.

How to use
  1. Choose the drawing scale [25/50/100] (the last value is remembered).
  2. Select the closed polylines on layer SHEAR-WALLS.
  3. The thickness is computed automatically and the text is oriented along the wall.
Notes: Polylines must be closed LWPOLYLINE on layer SHEAR-WALLS. Previous annotations are cleaned before redrawing.

SHEARWALL-TAB

Summary table of shear walls (Name / Thickness / Length).

How to use
  1. Choose the scale (25, 50 or 100).
  2. Select the wall labels (layer SHEAR-WALLS-TEXT).
  3. Click the table insertion point.
  4. The table is sorted by wall number — CSV export is available.
Notes: Labels must contain 'TH=' followed by the thickness (format 'Vx TH=ep'). The length is measured automatically from the nearest SHEAR-WALLS polyline.

TABLE-COLUMN

Summary table of columns with a drawing of each section.

How to use
  1. Select the column MTEXT labels (layer S-COLUMN-TEXT).
  2. Click the table insertion point.
  3. The table is generated with the sections drawn and dimensioned.
  4. Each unique column type is shown once.
Notes: Labels must be MTEXT with the name on the 1st line and the dimensions (BxH) on the 2nd. Sections are drawn at 1/25 with automatic dimensioning. Dimension style Scale25 and layer 'Column Table' are created automatically.

TABLE-ISOLATED-FOOTING

Reinforcement schedule table for isolated footings.

How to use
  1. Select the footing annotations (layer FOOT_ANNOTATION).
  2. Click the table insertion point.
  3. The reinforcement table is generated automatically.
  4. CSV export is available for Excel.
Notes: Dimensions are extracted and steel quantities are calculated.

TABLE-PURLINS

Summary table of purlins by group.

How to use
  1. Select all purlin annotations (layer Purlins_Texts).
  2. Click the table insertion point.
  3. The table is created on layer Purlin-Beam Schedule.
  4. A CSV export can be generated.
Notes: Annotations must be in the format 'N U-PP-LxH' (e.g. 3 U-PP-120X60). The G# groups must be present in the drawing.

ANN-PILES

Annotation and CSV export of piles.

How to use
  1. Choose the scale [25/50/100/200/250] (the last value is remembered).
  2. Enter the pile depth (m) (default 12.00).
  3. Enter the starting pile number (default 1).
  4. Select the circles on layer PILES_DRAWING.
  5. Each pile is annotated with its number, depth and diameter.
  6. Choose where to save the CSV file, which opens directly in Excel.
Notes: Circles must be on layer PILES_DRAWING.

ROTATE-PILE-ANOT

Rotates pile annotations around their own center.

How to use
  1. Enter the rotation angle in degrees.
  2. Select the annotations to rotate (layer PILES_ANNOTATION).
  3. Each object rotates around its own center — nothing is moved.
Notes: Works on MTEXT, TEXT, LWPOLYLINE and INSERT of layer PILES_ANNOTATION. The operation can be undone (UNDO). The rotation is added to the current orientation.

PILES-TABLE

Pile table with coordinates and characteristics.

How to use
  1. Choose the scale [25/50/100].
  2. Select the pile labels (layer PILES_ANNOTATION, MTEXT).
  3. Click the top-left insertion point of the table.
  4. The PILES SCHEDULE table is generated automatically.
Notes: Annotations must contain number, X, Y, diameter and depth. Layer PILES_TABLE is created automatically (color 121). The table includes a title, a header and vertical separators.

SECTION-PLAN

Draws the section symbol on a plan (line, triangles and labels).

How to use
  1. Choose the scale [25/50/100/200] (default 100).
  2. Enter the section name (e.g. A-A).
  3. Click the first point of the section line.
  4. Click the second point.
  5. The line, the arrow triangles and the labels are drawn and grouped.
Notes: Layer SECTION_ANNOT is created automatically. The linetype is loaded from acadiso.lin.

PIPE-LABELS-WATER

Annotates the nodes of a water network.

How to use
  1. Select the water network polyline (LWPOLYLINE).
  2. Choose the scale [50/100/200/250] (default 100).
  3. Enter the first node number (default 1).
  4. Enter the starting water level (m).
  5. Enter the slope (e.g. 0.01 for 1%) (default 0.01).
  6. Each vertex receives a node number and a computed level with a circle symbol and a leader.
Notes: Layers WATER_LEVEL and WATER_NAME are created automatically. The slope is subtracted cumulatively between nodes.

Panel COTA

AXIS-DIM

Continuous dimensioning of plan axes.

How to use
  1. Select the axis lines (LINE objects on layer AXES).
  2. Specify the dimension line location.
  3. Chained dimensions are created across all selected axes.
Notes: Works only on lines of layer AXES. Layer DIMENSIONS is created automatically. The dimension style defined for the command is restored.

CONTINUOUS-DIM

Continuous dimensioning by intersection with a cutting line.

How to use
  1. Select the objects to intersect (lines, polylines or blocks).
  2. Click the START point of the cutting line.
  3. Click the END point of the cutting line.
  4. Click the location of the dimension line (offset).
  5. Chained aligned dimensions are created at the intersections.
Notes: Layer DIMENSIONS is created automatically in red. If no intersection is found, an error message is shown.

OBJECT-DIM

Automatic dimensioning of lines and polylines.

How to use
  1. Select the lines or polylines to dimension.
  2. Enter the offset distance for the dimensions (e.g. 100).
  3. Each segment receives an aligned dimension.
Notes: Layer DIMENSIONS is created automatically in red.

Panel BoQ

VOLUME-RAFT

Volume take-off of rafts with a table.

How to use
  1. Choose the scale [25/50/100].
  2. Select the raft polylines (layer RAFT).
  3. Click the table insertion point.
  4. Numbers are placed on each raft.
  5. CSV export is available.
Notes: Level annotations (+X.XX) and thickness annotations must be on layer RAFT_ANNOTATION. Layer RAFT_VOLUME_TABLE is created automatically. The table includes totals.

VOLUME-STRIP-FOOTING

Take-off of strip footings and blinding concrete.

How to use
  1. Choose the scale [25/50/100].
  2. Enter the footing thickness (m).
  3. Select the closed polylines (layer Wall-Footing).
  4. Click the table insertion point.
  5. CSV export is available.
Notes: Polylines must be CLOSED on layer Wall-Footing. Blinding concrete is computed automatically (10 cm thick, 10 cm overhang).

FOOTING-BOQ

Bill of quantities of isolated footings.

How to use
  1. Choose the scale [25/50/100].
  2. Select the footing labels (layer FOOT_ANNOTATION, format S#/F#).
  3. Click the table insertion point.
  4. Quantities are grouped by footing type.
Notes: Labels must start with S# or F#. Dimensions must be in the format LxlxH (e.g. 120x120x60 in cm) on the same layer. The table gives concrete and blinding concrete volumes.

CAL-EXCAV-FOOT-ISOLATED

Excavation and backfill calculation for isolated footings.

How to use
  1. Choose the table scale [25/50/100] (default 100).
  2. Enter the total excavation depth (m) (default 1.20).
  3. Enter the excavation offset (m) (default 0.20).
  4. Select the footings on layer S_FOOTING.
  5. Click the table insertion point.
  6. Choose where to save the CSV file (default name Earthwork_Detailed.csv).
Notes: Section texts are read automatically from layer FOOT_ANNOTATION. The footings must be LWPOLYLINE objects on layer S_FOOTING.

CAL_RAFT_CUBATURE

Excavation volumes for general rafts, with structural deductions.

How to use
  1. Choose the table scale [25/50/100] (default 100).
  2. Enter the total excavation depth (m) (default 1.0).
  3. Enter the excavation offset/clearance (m) (default 0.0).
  4. Select the rafts (LWPOLYLINE on layer RAFT).
  5. Click the table insertion point.
  6. Choose where to save the CSV report (default name Raft_Volumes_Final.csv).
Notes: A summary table is generated in the drawing and the results are exported to CSV.

GR-BEAM-TAKEOFF

Take-off of ground beams with a table and Excel/CSV export.

How to use
  1. Select the ground beam polylines and their text annotations together.
  2. Choose the output option [CAD/Excel/Both] (default Both).
  3. Click the insertion point of the table.
  4. If Excel or Both is chosen, select where to save the CSV file, which opens directly in Excel.
Notes: Annotations must be in the format GBwxh (e.g. GB 30x60). Layers Gr-Beam, Gr-Beam-TXT and TAKEOFF-RESULT are used.

GR-SLAB-TAKEOFF

Take-off of the ground slab with deductions.

How to use
  1. Choose the scale [25/50/100].
  2. Select the slab contour polyline (layer DALLAGE).
  3. Select the ground beams (layer Gr-Beam).
  4. Select the columns (layer COLUMN).
  5. Select the shear walls (layer SHEAR-WALLS).
  6. Click the table insertion point.
Notes: The net area deducts ground beams, columns and shear walls; results are exported to CSV. The thickness is read automatically from layer DALLAGE_ANNOTATION. Layer GR-SLAB-TAKEOFF is created automatically.

QUANTITY-BEAMS

Beam take-off with a table and Excel export.

How to use
  1. Select the beam polylines AND their annotation texts.
  2. Click the table insertion point.
  3. Choose to export to CSV if desired.
  4. The table is created on layer TAKEOFF-RESULT.
Notes: Beam polylines are on layer S-BEAMS-2D, annotations on S-BEAMS-TXT in the format BxH (e.g. 30x60 or 30X60). The nearest beam to the text is used for association.

VOLUME-SLABS

Volume take-off of mixed slabs with a table.

How to use

  2. Select the slab polylines (layer SLAB_STRUCTURE).
  3. Click the table insertion point.
  4. Numbers are placed on each slab in the drawing.
Notes: Type (Solid/Hollow-core) and thickness text annotations must be close to the center of each slab. Layer REPORT_TABLE is created automatically.

QUANTITY-DROP-PANEL

Drop panel take-off with a table and Excel export.

How to use

  2. Enter the slab thickness to deduct (m).
  3. Select the drop panel polylines (layer Drop-Panel-Outline).
  4. Click the table insertion point.
  5. Choose the CSV export file.
Notes: The net volume of each drop panel deducts the current slab thickness. The gross thickness is read from the Drop-Panel-Annotation annotations. Layer REPORT-DROP-PANEL is created automatically.

Column volume take-off with a table and Excel export.

How to use

Panel PLOTING

LAYOUT-GEN

Automatic generation of layouts with viewports.

How to use
  1. Choose the paper format [A4/A3/A2/A1/A0].
  2. Enter the single scale (e.g. 50 for 1/50).
  3. Click the two corners of the area to frame in the model.
  4. Repeat for each page — press Enter to finish.
Notes: Layouts are named 'Page N' automatically, and numbering continues after existing pages. A viewport, a frame and a title block are created. Layers _VIEWPORTS_CYAN and _PAPER_FRAME are created automatically.

ORGANIZE-LAYOUT

Groups viewports into a combined layout.

How to use
  1. Choose the final paper format [A4/A3/A2/A1/A0].
  2. The layout COMBINED-TOTAL is created automatically.
  3. Viewports of all 'Page X' layouts are copied and arranged in a grid.
  4. A simplified title block is drawn.
Notes: Only layouts whose name starts with 'Page' are processed. Main viewports (ID=1) are ignored. Layer _PAPER_BORDER is created automatically.
